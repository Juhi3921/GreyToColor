# Grey To Color

where a grayscale image hides all its colors. 
You can move your mouse over the image to see the original colors appear through a circular reveal effect.

I built this project using HTML, CSS and JavaScript. I did not use any frameworks.



Keyboard Controls

+ / = → Increase reveal size

- → Decrease reveal size

R → Reset settings



How to Use

-Move your mouse over the image.

-Use  Reveal Size slider to make  circle bigger or smaller

-Click anywhere, on page to make the reveal expand for a moment

-Press R to reset everything

-Use Controls button to hide or show the control panel
